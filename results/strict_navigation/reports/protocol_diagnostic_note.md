# 首个严格模型：阶段审计与新增对照
时间：2026-09-10 14:12 北京时间；非最终结论。

训练已完成10轮、51920优化步，耗时5914秒（约98.6分钟）。分割与训练归一化审计通过，最终权重已保存。前28个正式评估输出的逐例成功记录和官方指标一致。

完整300例短目标测试：50步执行预算SR94%，150步预算SR95%；后者排除初始已达目标的24例后为261/276=94.6%。这仅说明已知TwoRoom布局的新轨迹短程控制有效，不能外推未知地图。

完整100例验证：默认长目标62%，等候选预算高频反馈62%，额外候选预算高频反馈44%，H10等候选预算28%。这些设置明确关闭热启动，与旧轮默认热启动条件不同，不能拼接为跨轮性能变化，更不能直接宣称高频反馈有害。

代码核验发现：重规划时热启动保留未执行动作后缀；关闭时每次从零均值重新搜索。默认H5/R5没有剩余后缀，而H5/R1和H10/R5会受到此选项影响。因此已在验证集增加三组热启动对照（各100例），检验交互作用。

100例开发性候选审计中，最终64候选动作池的物理动作分量平均27.5%超出[-1,1]。环境step明确截断动作，但原CEM把未截断动作输入预测器。这里的27.5%仅属于该小候选审计，不是所有正式规划的执行截断率。已增加三组动作投影对照（各100例）：默认、冷启动高频、热启动高频。候选在预测和CEM分布更新前投影到物理执行范围；最终均值保持在凸边界内。这是必要的简单接口基线，不是新算法贡献声明。小规模模型冒烟已通过；正式对照尚在运行。

同一审计中，预测代价与真实执行终点latent代价的Spearman中位数约0.131；真实latent代价与门中心路径代理的中位数约0.453。开放环15模型步误差均值约0.233、真实历史校正约0.024。相关性受候选收敛范围、动作截断和表示影响，不能单独确定因果或推出完整导航提升；一个5步前缀的oracle选择不能冒充完整闭环oracle实验。

此前300条test病例已用于能力和机制探索，现从原始1000条heldout轨迹中的未使用轨迹再冻结300例final_reserve，完全不参与训练、归一化或开发性评估。只在方法和超参数冻结后用于最终确认。旧划分文件及哈希不变，另存final_reserve_manifest.json。新旧病例仍共享地图；跨地图结论仍需另行验证。

两次独立训练种子3073/3074及相同短/长默认基准已加入唯一串行队列，位于当前阶段之后；没有重复启动GPU任务。多布局训练、轻量迁移头/策略先验、复杂拓扑和条件性部分观测仍待阶段审阅推进。
