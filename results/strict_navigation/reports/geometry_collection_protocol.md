# 单布局与多布局：匹配数据采集对照

这是用于区分训练布局覆盖与模型局限的新增控制实验，不是原始LeWM数据集的重新复现。已有单地图模型在变化布局失败，只能说明当前模型加训练分布的能力有限，不能据此判定LeWM架构无法泛化。

两组均重新采集8,000条训练轨迹与1,000条验证轨迹，逐回合长度沿用原严格训练/验证组长度，训练总帧数736,684、验证92,354。使用相同回合种子、行为混合比例、动作幅度和渲染环境。单布局组使用原墙方向、门位置49；多布局组使用预留8个训练布局，验证为4个不同几何布局。6个测试布局不参与采集。目标点重新随机采样，不取评估病例。

每个布局的采集行为严格平衡：50%回合为每5步重新采样的持续随机动作；50%回合使用几何信息引导的航点控制并加入固定幅度动作噪声。此处使用墙与门信息的是离线采集器，属于额外的数据监督/采集先验；训练模型仍只接收图像和动作，不输入地图坐标。多布局与单布局的新数据组共享这项额外条件，不能把相对原作者数据训练模型的变化完全归于布局覆盖。实际跨门、停滞、状态访问覆盖将按布局和行为审计。

每一帧记录执行前图像、状态与随后动作，保留完整回合索引，训练与验证不共享轨迹。归一化只由新训练组计算，使用ddof=1。后续训练须读取对应新归一化；不能继续用旧模型统计评估新模型。

已完成各24回合的小规模检查，每组72次图像重渲染、72次动作状态转移均匹配，训练统计与官方数据加载接口均通过。最初烟测发现行为模式按全局回合交替会与布局轮换绑定，正式采集前已改为每布局内部平衡；旧烟测保留但不作性能证据。

正式采集由两个CPU进程进行，每个进程上限3小时，不占GPU，不扩容服务器。唯一GPU队列会在4个单环境在线时延基线结束后启动采集；启动记录不代表采集完成。后续批量评估耗时如与采集重叠，不能当作隔离负载的在线性能。采集完成后须审计完整性、覆盖和数据配对，再安排匹配训练，不能因准备代码就称多布局训练已完成。

后续顺序：审计collections目录两组summary、manifest、normalization与逐回合记录 → 接入对应统计并做训练/评估冒烟 → 相同模型配置和更新预算训练单布局/多布局控制 → 在共同验证几何病例比较原始代价与候选迁移方法 → 冻结协议后再使用最终保留病例。新连通拓扑和部分观测仍是后续阶段。
