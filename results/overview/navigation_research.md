# LeWorldModel × 导航：首轮阅读与实验设计
调研日期：2026-09-09。实验和资料保存于本服务器 /root/autodl-tmp/lewm_research/。
本文区分论文已有结论、可借鉴组件、待验证研究假设。论文结果不等于本机复现结果；本机实测另见 experiment_report.md 和 runs/*/metrics.json。

## 1. 建议先研究什么

建议先把问题限定为**图像目标导航（Image-goal Navigation）**：给定当前图像和目标图像，机器人通过视觉和动作历史到达目标。暂不把语言理解、开放词汇目标识别与导航控制全部同时引入。

第一阶段：TwoRooms 的可控诊断；第二阶段：未见布局、多门洞和局部观测；第三阶段：第一人称 3D 图像目标导航。TwoRooms 是俯视像素环境，不能把它的成功率当作真实室内导航能力。

优先研究的问题是：**在有限算力和部分可观测条件下，如何让小型 JEPA 世界模型提出“有数据支持、可执行、能随新观测修正”的导航子目标？**
这是本轮阅读后的研究假设，不是已经证明有效的新方法，也不能据此认定尚无人做过。

## 2. 基础与代表论文

### 2.1 LeWorldModel（LeWM，2026 预印本）
[论文 v3](https://arxiv.org/html/2603.19312v3) · [官方代码](https://github.com/lucas-maes/le-wm)

图像经可训练编码器映射到紧凑 latent，动作条件 Transformer 预测下一 latent。训练使用预测 MSE 与 SIGReg 两项损失，不依赖像素重建、目标编码器 EMA 或冻结预训练视觉骨干。SIGReg 用随机投影的一维正态性检验约束整体表征，防止坍塌。规划时，CEM 搜索动作序列，以预测终点和目标的 latent 距离评分，再用 MPC 执行短前缀并重新规划。

对导航的意义是低成本预测；不足是“表征不坍塌”不保证“欧氏距离反映可达性”。原论文明确讨论了 TwoRooms 的弱项。不能把所有导航失败都归因于正则：还需要区分预测、目标度量和搜索三个来源。此次使用的官方代码提交为 8edfeb336732b5f3ce7b8b210d0ba370a09e2cac。

### 2.2 PLDM（NeurIPS 2025 主会）
[正式发表页](https://papers.nips.cc/paper_files/paper/2025/hash/3e7cf447f21cd11c846463affefce665-Abstract-Conference.html) · [全文](https://arxiv.org/html/2502.14819)

从无奖励离线轨迹中学习 latent dynamics，再进行目标条件规划。核心贡献不仅是模型，还有系统比较数据质量、数量和环境变化对模型式规划与无模型 RL 的影响。正式摘要强调：模型式规划在未见布局和数据效率方面更强，轨迹拼接与领先无模型方法相当；不能笼统宣称所有条件下全面胜出。

最值得借鉴的是数据与泛化实验设计：同一训练规模下控制轨迹质量、布局和覆盖，而不是只在单一地图汇报平均成功率。它是 LeWM 导航实验的重要对照。

### 2.3 DINO-WM（ICML 2025）
[正式发表页](https://proceedings.mlr.press/v267/zhou25t.html) · [全文](https://arxiv.org/html/2411.04983)

冻结 DINOv2 的空间 patch 表征，学习动作条件的未来特征预测，并在测试时优化动作。空间 token 更容易保留墙、门洞、物体等局部关系，但预测和规划开销更大。

对 LeWM 的启发是检查单个全局向量是否丢失对导航关键的局部结构。可以比较 CLS-only 与少量空间 token，但需要固定或明确报告额外算力；“换成 DINO”同时改变预训练数据和表征容量，不能归因于一个模块。

### 2.4 Navigation World Models（NWM，CVPR 2025）
[正式发表页](https://openaccess.thecvf.com/content/CVPR2025/html/Bar_Navigation_World_Models_CVPR_2025_paper.html) · [全文](https://arxiv.org/html/2412.03572v2) · [代码](https://github.com/facebookresearch/nwm)

用动作和时间间隔条件的扩散 Transformer 预测未来视觉状态，也能给外部策略采样的轨迹评分。不同于 LeWM，它保留生成未来图像的能力。重要实验包括轨迹预测误差、候选轨迹排序和规划约束。

可借鉴“策略提议—世界模型评分”的接口，以及统一动作/时间标度。论文主模型规模与训练算力远大于本机预算，不建议在单张 5090 上从零复现其最大模型。生成画面逼真、离线轨迹误差低与闭环成功是不同证据。

### 2.5 NavMorph（ICCV 2025）
[全文](https://arxiv.org/html/2506.23468) · [官方代码](https://github.com/Feliciaxyao/NavMorph)

针对连续环境视觉语言导航，用 RSSM 风格的确定性历史与随机状态建模环境；推断网络结合观测与历史，预测网络提供未来视觉特征和动作。Contextual Evolution Memory 检索和更新场景上下文，支持在线适应。

对 LeWM 最有价值的是显式记忆：相同当前画面可能对应不同历史位置，短窗口不一定足够。需注意其 CEM 是“上下文演化记忆”，不是 LeWM 的 Cross-Entropy Method。跨测试 episode 的记忆会改变评测条件，必须与每 episode 清空的设置分开报告。

### 2.6 PiJEPA（CVPR 2026 Workshop，非主会）
[正式发表页](https://openaccess.thecvf.com/content/CVPR2026W/WDFM-EAI/html/Chahe_Policy-Guided_World_Model_Planning_for_Language-Conditioned_Visual_Navigation_CVPRW_2026_paper.html) · [全文](https://arxiv.org/html/2603.25981)

以经过微调的 Octo 策略产生语言条件动作分布，再用它初始化 JEPA 世界模型上的 MPPI 搜索。世界模型与策略共享冻结视觉编码器，动作需要在策略和预测器间统一坐标系。任务同时给目标图像与语言，不能视为纯文本目标导航。

可借鉴候选动作先验与有限预算比较。但“用策略初始化 CEM/MPPI”已有明确先例。若接到 LeWM，应与相同候选数、相同时间预算的随机初始化和纯策略进行比较。

## 3. LeWM 发布后，哪些方向已经有人做了

### 3.1 RC-aux（2026-05 预印本）
[全文](https://arxiv.org/html/2605.07278) · [官方代码](https://github.com/Guang000/RC-aux)

同时修正时间和空间不匹配：用多步 open-loop 预测减少训练/规划差异，并训练预算条件的有向可达性函数 R(z,z',h)。监督来自轨迹的时间间隔，包含时间困难负样本和预测 latent 输入；规划时可把可达性加入评分。

因此，“LeWM + 多步预测 + 可达性辅助损失”已经不是空白。一个重要限制是：轨迹走了 Δ 步，不等于最短路径必须走 Δ 步；不同轨迹的状态也不一定互不可达。后续若研究监督噪声，需要专门验证，而非把这些标签当成精确物理真值。

### 3.2 TRM（2026-05 首版，2026-08-31 v2，预印本）
[最新全文](https://arxiv.org/html/2605.22164v2)

冻结世界模型，另学小型时间成对代价，替换或补充终点 latent MSE。它强调候选轨迹排序，而非只看特征能否解码位置。v2 在其“高距离范围、排除评测 episode 的训练”协议下报告 96.7% 成功；该数字不能与 LeWM 默认随机 goal-offset 评测直接比较。

尤其需要核对附录：改变门洞/墙方向的实验测试的是 geodesic pair head，不是对 temporal TRM 未见布局泛化的直接证明。论文显示布局变化和覆盖仍是边界。要研究新方法，必须把原始 MSE、TRM 和自己的方法放到相同 episode 与预算下。

### 3.3 HWM（2026 预印本，未在本轮确认主会录用）
[全文](https://arxiv.org/html/2604.03208)

在共享 latent 空间中训练不同时间尺度的预测器，把动作片段编码为宏动作。高层预测 latent 子目标，低层 MPC 追踪。论文覆盖操控和 maze 导航；导航实例建立在 PLDM 上，并考察更大未见布局。

它提供很直接的分层接口，但不是简单“无需训练的规划技巧”：新增高层模型和宏动作编码器需要训练。把 HWM 接到 LeWM 有实现价值，但单纯组合不能自动形成新论文贡献。

### 3.4 Hi-LeWM（2026-07 预印本）
[全文](https://arxiv.org/html/2607.12547v2)

直接研究冻结 LeWM 后添加高层模型。结果表明，普通高层 CEM 可能比平坦 LeWM 更差：搜索会找到训练数据不支持、预测终点代价很低但低层无法执行的宏动作。围绕真实训练动作编码进行受约束搜索，可以恢复部分收益。

这给出关键设计要求：子目标需要数据支持和可执行性，且执行时长应匹配。其主要证据来自 PushT，不能直接移植为导航结论。我们应先测低层能否追踪真实观测子目标，再判断错误来自高层预测还是低层控制。

## 4. 两篇补充阅读

[World-In-World，ICLR 2026 主会](https://proceedings.iclr.cc/paper_files/paper/2026/hash/5b4263be85820683d78675cc18d2efc7-Abstract-Conference.html)：本轮核验正式发表页与摘要。其评测立场很有用：闭环任务成功应优先于孤立的生成画质；可控性、动作观测数据与推理预算都重要。此处不声称已逐节精读全文。

[ReL-NWM，更新稿](https://arxiv.org/html/2511.11011)：同一 arXiv 编号早期检索题名为 LS-NWM，现有全文题名为 Efficient Image-Goal Navigation with Representative Latent World Model。采用 DINOv3 表征、TokenLearner 压缩、FiLM 动作融合与时空注意力。其录用状态本轮未核实，不把早期版本的数字和新架构混写。

## 5. 可以结合的三个具体研究方向

### A. 带局部几何与记忆的可达性评分：优先
假设：图像相似不等于可达，相似走廊甚至会产生位置混淆。让代价依赖“当前记忆状态、局部障碍/通道表征、目标与预算”，而不只依赖两个全局 latent。

可实现的最小版本：
1. 先冻结 LeWM，缓存历史观测 latent 与相邻动作连接，构建 episode 内记忆。
2. 学习一个小型可达性/时间代价模块；可加入从像素学习的局部墙/门洞 token。
3. 在同一组 CEM 候选上比较原始 MSE、普通成对代价与记忆条件代价，先定位排序差异。
4. 再评估闭环绕墙、门洞改变与局部遮挡。几何真值只能用于 oracle 诊断；若训练用了深度、位姿或分割监督，必须明确增加了信息条件。

预期区别于已有 TRM/RC-aux 的候选切入点，是**部分可观测和布局变化下，记忆如何帮助代价识别可达性**。这仍需更广检索和对照，不能仅凭组合宣称新颖。

### B. 从真实记忆节点选择可执行子目标：第二优先
高层先在已观测、或训练数据支持的节点间规划；低层用 LeWM 预测和执行短程动作。只有通过可达性与不确定性检查的边才加入规划。

应与普通 HWM、Hi-LeWM 的数据支持约束、纯检索拓扑图+低层控制比较。真实观测子目标减少幻觉，但不能凭空解决未知区域探索；未探索门洞需要额外的信息收集策略。

可研究“何时切换子目标/何时重新观察”，而不是固定时间执行。一个方向是假设：由预测误差和记忆不一致触发重新规划，能在相同预算下提高可靠性。必须测试是否只是调用了更多次编码器或获得了更多环境步数。

### C. 策略先验与规划预算分配：便于工程落地
用轻量行为克隆或检索到的动作片段初始化 CEM；在高不确定状态增加候选或缩短执行前缀。借鉴 PiJEPA/NWM，但不必一开始就引入 Octo 和语言模型。

必须报告成功率—墙钟时间曲线、候选数、预测器调用次数。相同随机种子和 episode 下比较：纯策略、随机初始化 LeWM、先验初始化 LeWM，以及自适应预算。单纯 warm start 已有先例，创新更可能来自“何时相信先验、何时增加搜索”的可验证机制。

## 6. 建议实验协议

先完成官方基线可运行性，再按下面顺序推进：

| 阶段 | 环境与划分 | 目的 | 主要指标 |
|---|---|---|---|
| 0 | 官方 TwoRooms，官方权重与配置 | 验证安装、状态重置、动作归一化、闭环规划 | success、运行时间、轨迹 |
| 1 | TwoRooms，固定且成对的起终点 | 区分模型误差与代价排序错误 | success、终点距离、候选排序相关性 |
| 2 | 保留未见门洞位置、墙方向和多房间布局 | 检查是否真正跨布局泛化 | success、路径效率、碰撞、预算 |
| 3 | 局部视野/遮挡/相似房间；每 episode 清空记忆 | 检查历史记忆的价值 | success、回访次数、迷路/卡住比例 |
| 4 | 3D 第一人称图像目标导航 | 验证能否迁移到实际导航设置 | SR、SPL、碰撞率、端到端时延 |

必要对照：原始 LeWM、随机策略、TRM 或 RC-aux、记忆单独加入、几何单独加入、完整方法；研究子目标时加入平坦与分层对照。条件允许时再加 DINO-WM/PLDM，避免一次铺开过多模型。

训练/验证/测试至少按完整轨迹划分，泛化实验还应按布局划分。滑动窗口随机切分可能共享相邻帧；官方脚本的划分不能不经检查直接用于论文级泛化结论。可达性头的训练对不能包含评测 episode。每个方法使用同一评测清单，至少三个训练或规划种子，并报告均值和不确定性。

严格分开：
- oracle 几何/最短路径只做故障定位，不并入纯视觉方法主结果；
- teacher-forcing 误差与 open-loop 误差；
- 数据集回放目标评测与真正未见环境；
- 图像生成质量、候选排序质量与闭环控制成功；
- 试运行与训练收敛后的正式复现。

## 7. 本轮实施约定

实验使用服务器已有 RTX 5090 和 CUDA 兼容 PyTorch，依赖安装于独立 venv，数据、缓存、权重和日志置于数据盘。WandB 离线，不上传实验记录。
官方源码保留；run_eval.py 只包装随机种子、视频目录与 JSON 记录，run_train.py 加入本地训练记录。若遇到接口兼容修正，会在实验报告中逐项记录。
目录中的 papers/sources.json 保存来源，papers/*.html 保存下载的原始正文，papers/download_manifest.json 保存下载校验信息。

可优先阅读的顺序：LeWM → PLDM → TRM → RC-aux → Hi-LeWM → HWM → NavMorph → NWM/PiJEPA。先弄清“为什么预测正确但仍然走不到”，再决定是否增加记忆、几何或语言模块。
