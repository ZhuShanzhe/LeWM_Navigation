# LeWM 导航能力与方法迁移研究

## 研究目标
评估 LeWM 作为导航世界模型的能力边界，定位主要瓶颈，筛选可从 WM+Navigation 文献迁入的组件，为后续选题提供依据；不是继续全任务复现原论文。使用现有单卡服务器，不扩租，不进行真实机器人实验。用户明确本轮不设 12 小时时限，但每个阶段有有限实验清单，不无限扫参。

## 核心能力与实验顺序
1. 可信导航基准：作者 TwoRoom 数据按完整轨迹 80/10/10 划分；完全相同的状态+动作轨迹归同组。训练、归一化、辅助头和动作检索库不得使用测试轨迹。固定验证 100 例、测试 300 例；先记录自然分布，再建等欧氏距离的同侧/跨墙配对，区分距离与绕行。
2. 能力与瓶颈：短目标、长目标、绕墙、低层子目标跟踪；候选动作经真实模拟器回放后比较预测评分、真实 latent 评分和任务进展。模拟器真值只作 oracle 诊断，不进入纯视觉主方法。记录真实预测调用、候选展开、编码量、环境步数及在线延迟。等预算是明确资源上限，不将成功早停后的实际消耗混称完全相同。
3. 未知地图：先测试门位置/墙方向变化，明确这仍是 TwoRoom 几何迁移；再建立多布局训练/验证/测试及多房间拓扑压力测试。保持观测渲染与物理碰撞一致，先验证任务可解。不能仅凭单地图模型在新地图失败就判定架构不能泛化。
4. 迁移参考与稳定性：冻结 LeWM 的代价替换（TRM 风格）、数据支持的子目标/拓扑图、策略先验提议+LeWM评分三条路线按诊断结果择优实现最小对照。原版、简单规则和匹配资源基线必须有；阅读官方实现决定何者可称忠实复现，简化实现必须标注 adapted/inspired。严格划分的主结果至少 3 个独立训练种子，不能把旧协议模型算作新协议重复。PLDM/DINO-WM 作为外部参照需核对数据和预训练信息。
5. 部分观测是条件阶段：全观测基准可信、存在历史消歧需求且基础控制可用才加入局部视野及无记忆/有限历史/记忆比较；每回合清空记忆。第一人称 3D 仿真是导航外部有效性评估候选，若实现/数据不可用需明确报告，不能以俯视 TwoRoom 代替。
6. WM+Navigation 前沿调研：正式会议信息独立核验，近期预印本明确标注；记录导航任务、观测/动作、额外监督、数据规模、核心模块、LeWM 接入位置、失败风险和最小迁移实验。重点 PLDM、DINO-WM、NWM、NavMorph、PiJEPA、RC-aux、TRM、HWM、Hi-LeWM、UniWM、ReL-NWM、NavWM 与新近动作条件兼容性 LWM。后续检索补缺但不按论文数量凑清单。

## 结论约束
不给候选方向预设赢家。不保证迁移会获得大提升；负结果同样保留。未知布局、离线预测、闭环导航和真实机器人结论严格区分。旧报告保留原样，新的综合报告分别列出旧探索证据与新严格协议证据，不把不同病例/预算/训练数据的百分比直接拼成排名。
