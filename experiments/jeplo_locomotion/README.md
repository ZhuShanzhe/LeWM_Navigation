# JEPLO 部署前运动评测

本目录包含两组独立记录：官方 README 部署配置下的 **6 条原生闭环检查记录**，以及历史 **385 次独立同步 MuJoCo 诊断**。两组均冻结部署权重，不训练、不连接机器人。原生组执行 C++ 控制、DDS、ZMQ 与 LiDAR 仿真；没有运行真实 ROS/Livox 硬件链路。

**原生组对齐官方推荐部署参数，但使用公开示例场景与自定义测试条件，不是论文定量性能复现。** 历史同步组不代表官方推荐配置；不能把其 30 cm 箱体卡住直接作为模型能力结论。JEPLO 是候选运动执行层，不是 image-goal 导航模型。

## 原生配置检查

| 条件 | 观察 |
|---|---|
| 官方 ONNX 样本 | ORT 1.22.0 / TensorRT 10.9 与 C++ 控制器自身校验通过 |
| 零指令站立 | 完成 10 秒闭环 |
| 前进 0.25 m/s | 约 8 秒观察段平均位移速度 0.219 m/s，含启动过程 |
| 转向 1 rad/s | 平均转向速度 0.755 rad/s |
| 公开双箱示例、持续前进 | 登高后越过平台边缘翻倒，不等同于无法登箱 |
| 双箱登顶后停止 | 登上 70 cm 平台，并通过自定义 2 秒姿态保持条件 |
| 公开楼梯示例 | 单次记录未完成登顶，随后翻倒 |

以上每个运动条件仅一条记录，默认 cage mask 随进程随机生成，不是稳健成功率估计。6 条记录均完成运行，但其中包含翻倒；“完成”不等于任务成功。另有 4 次环境或地形切换故障留档，不计为运动能力测试。详见[官方配置基准](docs/official_alignment.md)和[原始验收结果](results/README.md)。

## 历史同步诊断观察

| 项目 | 当前配置下的结果 |
|---|---|
| 平地指令 | 110 次均完成 10 秒测试；不能等同于跟踪准确 |
| 15 cm 楼梯 | 默认与 raw_actions 各 5/5 |
| 30 cm 箱体 | 默认 0/5，raw_actions 1/5；出现长时间受阻 |
| 50 cm 箱体 | 默认 4/5，raw_actions 5/5 |
| 低摩擦楼梯 | 默认 0/5 |
| 转向分项对照 | 当前仿真中髋关节半幅是误差增大的主要因素；不支持直接修改真机参数 |

每组只有 3 或 5 个初态/布局；不同模式共享病例。385 次不代表 385 个独立随机场景，也不是部署可靠性的充分证明。

## 无仿真依赖的数字核验

在仓库根目录运行：

```bash
python experiments/jeplo_locomotion/src/verify_results.py
```

该命令只用 Python 标准库，核验计数、病例对应关系、分组通过率、误差均值和外部证据字段。它不运行机器人模型。
