# 数据规模与验收

这里保存实际生成数据的聚合统计、验收状态及资源来源信息，不保存原始图像、目标掩码、完整回合或机器人轨迹。

调试场景的通过只说明场景接口、实例标识和采样流程已跑通，不代表正式数据集完成。正式规模以各任务完成生成后的summary和audit为准。不同任务的成功定义独立，生成的专家轨迹不是模型导航成绩。

## 已验收数据

- Gibson地点图像导航：86个场景、198,282个派生回合，6,949张目标图像；训练179,797、验证10,672、本地测试7,813。元数据、图片与场景隔离检查无错误。
- 训练场景专家／扰动轨迹：310条，均到达采集目标；这是数据采集质量，不是学习模型成功率。
- HSSD正式数据：168个场景，237,760个地点回合、228,176个物体实例回合、3,766个目标实例；训练场景专家／扰动轨迹550条。
- HSSD独立调试集：20个地点回合、40个实例回合、3个物体实例，不计入正式规模。

## 全量验收范围

254个场景全部通过，覆盖Gibson和HSSD共664,218个回合：

- 所有回合唯一性、完整目标图像、场景划分隔离、实例身份引用和场景统计检查。
- 逐回合重新计算路径，共3,226,414次最短路径查询；物体回合检查到整个有效接近视点集合的距离。
- 72,122张声明的实例多视角图像及掩码检查；48,937个实例接近视点在仿真中重新渲染并验证目标可见性。
- 860条训练轨迹、43,779帧图像与动作后的实际位置／朝向转移检查，全部通过。
- 原始56,606个HSSD文件完整存在，并生成本地SHA-256冻结清单。该清单用于本地可追溯性，不冒充独立上游校验和对比。

这不是学习模型闭环性能评测，也不是逐回合执行完整机器人动作。活动数据应以服务器冻结索引选择，不能直接遍历原始图片文件夹。
