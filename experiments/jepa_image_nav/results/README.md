# 数据规模与验收

这里保存实际生成数据的聚合统计、验收状态及资源来源信息，不保存原始图像、目标掩码、完整回合或机器人轨迹。

调试场景的通过只说明场景接口、实例标识和采样流程已跑通，不代表正式数据集完成。正式规模以各任务完成生成后的summary和audit为准。不同任务的成功定义独立，生成的专家轨迹不是模型导航成绩。

## 已验收数据

- Gibson地点图像导航：86个场景、198,282个派生回合，6,949张目标图像；训练179,797、验证10,672、本地测试7,813。元数据、图片与场景隔离检查无错误。
- 训练场景专家／扰动轨迹：310条，均到达采集目标；这是数据采集质量，不是学习模型成功率。
- HSSD独立调试集：20个地点回合、40个实例回合、3个物体实例；正式HSSD资源仍在下载，正式规模未统计。
