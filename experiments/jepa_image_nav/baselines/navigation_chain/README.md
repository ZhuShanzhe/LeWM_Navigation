# 导航链路基线与评测

目标图像、物体类别、语言指令和运动控制分别对应不同任务。这里使用预训练权重和原生推理模块，按任务配置场景、输入与成功条件，不训练或微调。跨任务的成功率不合并排名。

## 文件

- [results](results/README.md)：通过验收的汇总、数据构建记录、权重版本和无效实验标记。
- [scripts](scripts/README.md)：资源准备、原生模型适配、闭环评测与验收脚本。
- [literature](literature/README.md)：模型选择、架构与适用任务。
- [patches](patches/README.md)：第三方源码的兼容性补丁及原始版本。

服务器工作目录为`/root/autodl-tmp/jepa_instance_bench_20261016`。场景、照片和回合标签保留在服务器；仓库仅保存脚本、校验信息与汇总，不保存数据集、模型权重、API凭据、图像或逐步轨迹。

JEPLO站立组也完成3次且无持续大倾斜。持续大倾斜定义为机身直立方向余弦小于0.5并持续至少1秒，属于由原生位姿推导的诊断，不等价于完整接触状态的跌倒检测。每组仅3次，且上游笼架随机化未固定种子，不是三个受控训练种子。

GOAT全原生身体/navmesh另有300次执行，但转向或STOP时出现位置变化，未通过验收，排除于成绩表。零成功组不提供退化的`[0,0]`场景重采样置信区间。所有有效结果及无效标记以[汇总JSON](results/README.md)为准。

## 类别数据集

HSSD类别任务沿用15个测试场景，涵盖chair、couch、plant、bed、toilet、tv。目标类别的所有已识别场景实例均参与评分，不局限于原先图像目标选中的物体。826个识别实例中，579个具有采样验证视点，合计27,146个视点；其余247个没有通过当前有限采样，不能解释为不可达。

候选视点来自已有接近标签，以及24个方位与5种半径的组合。可见性门槛为像素占比至少2.5%。在模型测试之前，2个没有验证目标的plant任务被确定性替换为同场景chair任务并重新采样起点，形成完整300回合。替换记录、最终面板摘要与哈希均保留。不能把类别面板与实例面板当成完全相同的成对任务。

类别主指标采用“STOP6＋正确类别可见＋水平AABB间距≤1米”，不为这个目标集合附加不一致的稀疏视点SPL。另行保存“距已验证视点小于0.25米”的辅助SR与SPL；它们不替代主指标。

## 结果说明

已有结果提示需要重点检查停止决策、跨域感知、目标验证和运动稳定性。GOAT的大量提前停止并不能单独证明其视觉编码器缺乏实例辨识能力：检查点训练分布、冷启动任务形式、相机、几何与评分协议都可能影响结果。需结合UniGoal或另一完整实例方法，才能形成实例导航专用方法之间的对照。

Qwen预检中的格式故障是运行问题，修复后的10回合没有解析或随机回退；其成功率样本过小，不能推断长程语言推理能力。EB-Navigation采用原生距离到达判定，没有STOP或目标可见要求，因此不能与HSSD实例SR直接比较。

JEPA实验分别检验历史记忆、动作条件潜变量预测、探索候选排序与主动确认。保留相同感知、地图、执行和评分条件，设置静态编码器、只加记忆、只改停止头、等参数与等时间预算对照，区分算法收益与接口修正。低层JEPLO只用于评估执行环节，不能代替视觉语义导航。
