## 成功判定

GOAT原生动作0表示全局终止，动作6表示完成子目标；仅动作6可以触发这里的目标成功。实例任务还要求距冻结接近视点的geodesic距离小于0.5米，且同一个目标物体占当前图像至少2.5%。类别任务允许该类别任意识别实例，要求可见比例至少2.5%且水平AABB间距不超过1米。

类别辅助视点指标只检查STOP6与已验证视点geodesic距离小于0.25米，与主指标的集合不同。辅助SR为5/300、SPL约0.00608，而主SR为1/300，二者不能混用。

EB-Navigation保持官方自动到达判定：机器人与标注目标的水平欧氏距离不超过1米，最多20个动作。它不要求STOP、物体可见或特定朝向。不报告没有原生真值支持的SPL和nDTW。

JEPLO原生部署的登顶门槛由本项目规定：箱体前进至少4.15米且高度至少0.9米；楼梯前进至少8.05米且高度至少3.15米；两者均需直立余弦大于0.8并保持至少2秒。不是官方论文的成功定义。

## 验收范围

GOAT核对固定面板、349个策略权重键、动作argmax、STOP语义、相对GPS/compass、路径、评分与轨迹连续性。有效实例组中，异常长度的前进动作通过原生Habitat控制重放核对，保留地形投影和滑动效应；转向或STOP平移则不接受。类别组进行完整记录重算，但不声称额外独立视觉重放。

类别路径原生逐步float32范数与存储值完全一致。改用float64重算时，最大累计路径差约9.07×10⁻⁷米、最大SPL差约1.10×10⁻⁸；不修改原始成绩或放宽成功条件。

初始化、下载、CUDA、API和格式错误单独保留，不作为导航失败计入成功率。UniGoal和Jev在完整闭环通过前，不赋予成功率或失败率。
