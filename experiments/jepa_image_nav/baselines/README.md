# Image target 导航基线与性能对照

两类任务分别是到达目标照片的拍摄位置，以及到达照片中的同一个物体实例。主要对照使用公开预训练导航权重，不训练或微调。完整主评测为1,160次模型—回合执行，覆盖880个固定任务回合；另有280次转向接口对照。RGB-D辅助系统仅完成40/300回合，不进入主结果排名。

## 文件

- [scripts](scripts/README.md)：官方资源获取、RTX 5090推理适配、固定回合抽样、闭环评测和结果核对。
- [results](results/README.md)：完整主结果、分组表现、接口对照、资源版本和运行状态。
- [reports](reports/README.md)：模型筛选、评测设置与不足分析。

服务器目录为`/root/autodl-tmp/jepa_vln_baselines_20261015`。场景与任务来自已经验收的`/root/autodl-tmp/jepa_vln_data_20261014`，不改变场景划分、目标照片或成功阈值。

## Jev 与 JEPLO 的位置

[Jev-ObjNav](https://github.com/owlet914/jev-objnav)以目标名称驱动开放词汇ObjectNav，结合RGB-D、位姿、在线地图和Jev高层决策。现有接口并不要求找到图中的唯一实例；Jev通过外部服务接入，仓库不等于完整决策模型权重。其区域图、候选验证和探索记忆适合作为架构参照，直接把图片转成类别会丢失实例身份。本轮不调用付费接口，不把作者18个场景的演示统计当作本项目成绩。

[JEPLO](https://github.com/ASIG-X/JEPLO)解决LiDAR与本体感知条件下的四足运动执行，不负责图像目标搜索或识别。[JEPLO-Dataset](https://huggingface.co/datasets/ASIG-Lab/JEPLO-Dataset)包含8段真机记录，提供LiDAR、IMU、关节状态和轨迹真值，适合后续里程计与运动鲁棒性分析，不提供本项目需要的图像目标仿真任务。它保留为低层部署参照，不进入ImageGoal成功率比较。

## 完整主结果

全部使用RGB与目标图像，贪心动作选择，最多500次决策，无目标坐标、实例标签、目标掩码或全局地图输入。DEBiT采用10°转向；FGPrompt采用30°，因此不做同一动作空间下的直接算法排名。每个场景抽取20回合，按距离和绕行类型分层，不代表原始数据自然频率。

| 预训练策略 | 任务面板 | 场景 / 回合 | SR | SPL |
| --- | --- | --- | --- | --- |
| FGPrompt | Gibson原验证场景，地点目标 | 14 / 280 | 82.1% | 0.554 |
| DEBiT-S，10° | 相同Gibson回合，地点目标 | 14 / 280 | 66.4% | 0.464 |
| FGPrompt | HSSD本地测试，地点目标 | 15 / 300 | 22.0% | 0.143 |
| FGPrompt，地点权重迁移 | HSSD本地测试，同一物体实例 | 15 / 300 | 3.0% | 0.012 |

这些不是作者原论文的复现分数：回合重新采样，机器人与传感器按本项目协议设置，决策预算与推理选择也不完全相同。HSSD是合成室内场景迁移测试；实例任务不能据此评价专门训练的IEVE、UniGoal或DEBiT-IIN。

## 已观察到的不足

1. 跨场景分布迁移明显减弱。FGPrompt在HSSD地点任务有194/300回合停止在成功区域之外。场景、几何和任务分布同时变化，不能只归因于某一种视觉表征。
2. 路线距离和绕行仍有影响。FGPrompt在Gibson的3米以下回合成功率91.8%，10米以上为43.8%；在HSSD分别为40.4%和2.4%。两组均存在长程不足，但难度分布并不相同。
3. 地点匹配不能替代实例确认。FGPrompt实例面板有68/300回合曾清楚看到目标、47/300回合曾进入可见成功区域，最终仅9/300正确停止。13/300在其他已收录同类实例的停靠区域停止；该统计只覆盖拥有接近视点标签的其他实例，不能代表所有身份混淆。
4. 宽松到达不代表精确停靠。补充条件为距离小于0.25米且朝向差小于15°时，FGPrompt在Gibson为50.4%，DEBiT为1.4%。原模型未必以此为优化目标。
5. 控制接口会制造伪缺陷。相同DEBiT检查点、相同280回合和500决策下，30°失配接口SR为21.4%，10°对齐接口为66.4%，差45.0个百分点。它是接口效应，不是新算法收益。

## JEPA 对照实验的位置

保留FGPrompt作为30°RGB主基线；DEBiT作为对应关系表征参照，并保留其原生转向条件。物体任务需要补齐至少一个完整实例导航专用方法，不能只比较地点模型的零样本迁移。

JEPA扩展依次检验历史表征融合、动作条件潜变量预测、候选动作筛选和主动确认。固定编码器以外的感知、地图、控制与STOP条件，加入等参数静态编码器、只加记忆、只改停止头及等时间预算对照。目标是验证相同观测下是否更准确预测进展、可见性和错误候选，而不是预设加入JEPA一定改善结果。

## 数据与运行边界

HSSD测试集319个已收录目标实例中，120个复用了训练集中的目标资产，173个在本场景还存在同资产的其他已收录实例。场景隔离不等于资产隔离；同资产重复也不等于照片完全相同。后续需要分别报告未见场景、未见资产和重复资产干扰切片。

目标照片可带俯仰角，而当前动作仅包含水平转向。60回合真值控制器诊断有56个成功，3个实例回合到达所选接近点后仍未达到水平相机可见阈值；这不能证明不存在其他可见停靠点。完整水平视点核查尚未完成，不能把全部实例失败解释为模型识别不足。

GPU出现`cuInit=999`，驱动报告`GPU Recovery Action: Reboot`，实例重启后的复查仍未恢复。DEBiT的HSSD两项、RGB-D辅助面板余下260回合、水平可见性核查和独占推理延迟尚未完成。初始化错误不记作导航失败；恢复记录和完整状态见[结果说明](results/README.md)。
