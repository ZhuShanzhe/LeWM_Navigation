# 实验结论的适用边界

- 当前主结果是全观测俯视TwoRoom图像目标导航，不是第一人称VLN、未知地图建图或真实机器人部署。
- 门位置和墙方向变化仍是两房间几何变化；自建多房间更改了模拟器、尺度和外观，不能把差异单独归因于拓扑。
- 三训练种子共享测试病例；四图共享坐标。标准差不是置信区间，配对病例区间也不是对未知地图总体的不确定性估计。
- 早先300测试病例和旧几何参与过开发；最终另用未触碰预留。未来不可继续在此最终保留集上调参后仍称其未触碰。
- 时间标签是行为轨迹间隔，不是最短到达时间；检索、时间头有额外训练/数据处理成本。
- 候选模型步上限相同不等于总计算相同，提前成功后的实际用量不同；批次摊销时间不是机器人在线时延。
- 高原布局SR不能替代跨墙分层结果；仅检索用LeWM编码器，但不使用动作条件预测器。
- 路点实验使用特权真值且只有一个匹配种子对；8/16像素是开发敏感性分析，不是独立高层算法成果。
- 3个预留起点有第一步边界投影；主300例保留，另报共同297例敏感性。初始成功排除是另一种筛选。
- 部分观测、实机、全部大型论文基线、完整五方法在线延迟、PushT从零训练以及多房间三种子重复未开展。
- 权重/数据/原始trace未上传，公开仓库的数值复算不等于第三方从零闭环复现已经验证。
